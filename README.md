# SketchUp SKP / DWG Exporter для Blender 5.2

Расширение Blender для экспорта модели в форматы, с которыми работают SketchUp и AutoCAD:

* **`.skp`** — собственный файл SketchUp 2021+ (формат SketchUp 2025 «VFF»): компоненты,
  материалы, смягчённые рёбра. SketchUp SDK и сам SketchUp для экспорта не нужны.
* **`.dwg`** — чертёж AutoCAD R2000 (AC1015). Открывается в AutoCAD, nanoCAD, BricsCAD,
  а через *Файл → Импорт* — и в SketchUp Pro. Два режима содержимого:
  * **2D план (вид сверху)** — как в образце `1199.dwg`: видимые контуры модели с удалением
    невидимых линий, контуры зон безопасности и подпись кода, всё в блоке с именем модели;
  * **3D модель** — трёхмерные грани (3DFACE) с цветами материалов.

## Установка

1. *Edit → Preferences → Get Extensions → ▾ (меню справа) → Install from Disk…*
2. Выберите `skp_dwg_exporter-1.0.0.zip`.
3. Включите расширение «SketchUp SKP / DWG Exporter».

## Использование

*File → Export*:

| Пункт меню | Результат |
|---|---|
| SketchUp (.skp) | `.skp` |
| AutoCAD (.dwg) | `.dwg` |
| SketchUp + AutoCAD (.skp + .dwg) | пара файлов с одним именем, как `1199.skp` + `1199.dwg` |

Экспортёры также доступны в *Свойства коллекции → Exporters* (Blender 4.2+) — удобно
выгружать каждый МАФ отдельной коллекцией.

### Как модель превращается в SKP

* Каждый объект становится экземпляром компонента. Объекты с общим мешем (связанные
  дубликаты Alt+D, экземпляры коллекций) используют **одно** определение компонента.
* Материалы: цвет, прозрачность, metallic/roughness из Principled BSDF (текстуры не переносятся).
* Неплоские многоугольники триангулируются; диагонали и рёбра между гладкими гранями
  (угол меньше «Смягчать рёбра до») становятся мягкими, как в SketchUp.
* Модификаторы применяются; скрытые объекты пропускаются (настраивается).
* Размеры переносятся в реальном масштабе (1 м Blender = 1 м SketchUp).

### Как строится DWG-план

* Рисуются рёбра-границы, рёбра с изломом больше «Угол излома» и силуэтные рёбра
  (граница видимой с высоты части поверхности), затем удаляется всё, что закрыто сверху
  другими объектами (трассировка лучей по BVH Blender).
* Совпадающие и перекрывающиеся отрезки сливаются.
* Слои по умолчанию повторяют образец: `Юмагс_МАФ`, `Юмагс_ЗОНЫ БЕЗОПАСНОСТИ маф`,
  `Юмагс_КОД МАФ` (имена и цвета меняются в настройках расширения).

### Зоны безопасности

Нарисуйте контур зоны кривой или плоским мешем и сделайте одно из:

* положите объект в коллекцию, в названии которой есть «зона», «безопас», «safety» или «zone»;
* или в *Свойства объекта → Экспорт SKP / DWG* выберите роль «Зона безопасности».

Такие объекты попадают в DWG на слой зон (без удаления невидимых линий) и по умолчанию
не выгружаются в SKP. Там же можно исключить объект из экспорта или задать ему свой слой DWG.

## Ограничения

* Текстуры и UV в SKP не переносятся — только цвет материала.
* DWG пишется в версии R2000; для другой версии пересохраните файл в AutoCAD или
  ODA File Converter.
* Зоны безопасности не вычисляются автоматически — их контур рисуется в Blender.

## Как проверялось

* Формат SKP восстановлен по образцу `1199.skp` (SketchUp 2025). Модель образца
  загружена в Blender и выгружена обратно: геометрия совпала с исходной
  с точностью 3·10⁻⁵ дюйма; 2D-план, построенный из неё, совпал с `1199.dwg`.
* DWG проверен двумя независимыми читателями (Aspose.CAD и парсер ezdxf),
  контрольные суммы и карта объектов — отдельной проверкой.
* Открытие в самих SketchUp и AutoCAD не проверялось: на машине разработки их нет.
